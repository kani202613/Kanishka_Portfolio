    5-Factor Sentinel Risk Index Architecture

    When an autonomous AI agent initiates an MCP (Model Context Protocol) tool execution, SentinelMCP intercepts the JSON-RPC payload and evaluates risk using five discrete mathematical dimensions:

    • MiniLM Context Drift: Computes semantic cosine distance between conversational intent and tool argument semantics.
    • NetworkX Graph Anomalies: Builds real-time call-graphs to detect out-of-sequence or cyclical tool chaining attacks.
    • XGBoost Threat Classifier: Gradient-boosted model trained on lexical and structural exploit signatures.
    • Payload Entropy Scoring: Detects base64/hex obfuscated data exfiltration attempts.
    • Parameter Schema Enforcement: Strict validation of argument bounds and typing in SQLite audit store.

    Enforcement & Containment Flow

    Agent Tool Request (JSON-RPC)
  │
  ├── [1] Pre-execution Interception Layer
  │     ├── Parse tool_name & arguments
  │     └── Verify caller authentication token
  │
  ├── [2] 5-Factor Risk Scoring Engine
  │     ├── MiniLM Embedding Drift: 0.0 – 1.0
  │     ├── Call-Graph Anomaly Score: 0.0 – 1.0
  │     └── XGBoost Inference (Latency < 18ms)
  │
  └── [3] Policy Decision Gate (< 50ms)
        ├── If Risk < 0.65 ➔ Forward to Real MCP Server
        └── If Risk ≥ 0.65 ➔ Reroute to Mock Sandbox
