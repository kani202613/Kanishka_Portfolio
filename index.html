    Overview & Metrics

    Technology Decisions

    Node.js + Express
    Non-blocking, event-driven I/O loop is highly efficient for managing asynchronous, multi-stage GenAI prompt streams.
    MongoDB
    Flexible document model simplifies storing rich resume analysis and deeply nested AI-generated interview results.
    REST API
    Chosen for its simplicity, clear resource-based routing, and suitability for this application's request-response workflow.

    AI Interview Engine

    Built a custom orchestrator around the Gemini API that generates tailored, role-specific questions, parses user input responses, structures scorecards, and appends analytical improvement recommendations.

    Key Learnings

    • Designing clean, resource-based RESTful API routing structures.
    • Structuring full-stack asynchronous Node/React applications.
    • Integrating third-party AI models safely with robust prompt validation.
    • Managing complex asynchronous calls and error boundaries in Javascript.
    • Working with schema-less MongoDB document structures.

    Technical Challenge

    Challenge: Maintaining application responsiveness while waiting for AI-generated responses from Gemini API.

    Solution: Implemented interactive loading states, optimized JSON prompt instructions to minimize payload sizes, and cached session data in React Context to prevent unnecessary server requests and UI freezes.
